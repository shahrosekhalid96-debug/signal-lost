# Signal Lost

Top-down sci-fi survival game. Crash-landed on Kepler-7b — salvage six ship parts,
fight the local wildlife, collect alien artifacts, break into the vault for an alien
power core, and escape.

Play by opening `index.html` in any browser, or live via GitHub Pages.

## Features
- Open world with waypoint markers + minimap
- 3 weapons (axe, blaster, pulse rifle), 4 enemy types + a boss
- Ship workbench & marketplace: sell artifacts, buy upgrades and consumables
- Periodic helper supply drops
- Three-act story: salvage → vault/boss → escape

## Controls
WASD move · mouse aim · click attack · 1/2/3 weapons · E interact · Esc close menu
